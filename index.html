// what it does

It stops the commit before the secret exists in history.

The hook reads only the lines you're adding. A high-confidence secret is blocked outright by a deterministic detector — the model never sees it. An ambiguous one is settled locally, on shape features alone.

// architecture

One policy engine, two enforcement points.

The same detectors run wherever sensitive data could escape — the moment a human commits, and the moment an AI agent is about to send a payload to a model.

01 — commit time

The git hook

Inspects only the lines being added. Finds secrets and PII with deterministic detectors, lets a small local LLM settle the ambiguous cases — it sees only redacted shape features, never the value — explains the risk, and applies a developer-approved fix to the staged copy.

02 — ai runtime

The gateway

Runs the same detectors over an AI-agent, MCP-tool or RAG payload before a model sees it — masking secrets and PII, and neutralising indirect prompt injection carried inside retrieved content.

Design contract: deterministic first. The model can allow a medium case or escalate it to a block, but it can never unblock a high-confidence secret — and any error, timeout or bad response fails closed.

// invariants

Built so a leak can't slip through the tool itself.

DETERMINISTIC FIRST

Rules decide, not vibes

26 provider rules, entropy grading, checksum-valid PII and sensitive-file checks make the call. The model is a tie-breaker, not the judge.

FAILS CLOSED

Errors block, never leak

A timeout, bad JSON, a digest mismatch or a refused endpoint all resolve to WARN or BLOCK. Uncertainty is never a green light.

VALUE STAYS LOCAL

The secret never travels

No raw value ever reaches a prompt, the terminal or a log. The model gets masked shape features; a regression test guards it.

LOCAL-FIRST

Runs on your machine

The model is a small Qwen served locally. No cloud call is required to commit; nothing about your code leaves the laptop.

SAFE FIXES

Never re-triggers

Remediations rewrite the staged blob, keep unstaged work untouched, and are checked so the replacement can't set off a detector again.

EVERY REPO, ONCE

One install covers all

Protects every repository on the machine — including ones you clone tomorrow, and commits made by IDEs, GUI clients and AI coding agents.

// get it

The whole install is one line.

No pip, pipx or uv first. It builds an environment of its own and never touches your system Python. When it finishes, every repo on the machine is protected.

bash curl -fsSL https://getzerotrace.github.io/zerotrace/install.sh | bash
pwsh irm https://getzerotrace.github.io/zerotrace/install.ps1 | iex

macOS, Linux, WSL and Git Bash use the first line; Windows PowerShell uses the second. Remove everything it added — hooks, the environment, PATH lines — with zerotrace-uninstall (add --purge to drop the local model too). Air-gapped installs and what each step does live in docs/INSTALL.md.
