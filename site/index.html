Leave zero trace.

A guardrail that catches secrets and personal data at commit time and fixes them before they ever reach git history — in every repository on the machine, with one install.

macOS / Linux curl -fsSL https://getzerotrace.github.io/install.sh | bash
Windows irm https://getzerotrace.github.io/install.ps1 | iex

No pip, pipx or uv needed — it brings its own environment. Remove it again with zerotrace-uninstall.

Catches it before the commit

Only the lines you are adding are inspected, so a scan costs a moment, not a coffee break.

Explains, then fixes

Every finding says why it is risky and offers the fix — an environment lookup, a safe placeholder, or unstaging the file — applied to the staged copy with your approval.

Never phones home

Detection is offline. The optional local model only ever sees redacted shape features, never a value, and it can never unblock a high-confidence secret.

How the install goes

Six steps, and it tells you what it found at each one.

  1. Checks this machine — git, Python 3.11+, disk space.
  2. Creates its own environment — never your system Python.
  3. Checks Docker — installed? running? may this user use it?
  4. Installs the git hooks — every repository, present and future.
  5. Prepares the local model — optional; skip it with --no-model.
  6. Proves it works — stages a fake credential and checks the commit is refused.
